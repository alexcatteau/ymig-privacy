Politique de confidentialité Dernière mise à jour : 23 mai 2026 Ymig est 100% local. Aucune donnée ne quitte ton téléphone. Pas de serveur, pas de cloud, pas de tracking, pas de compte. 1. Données collectées Ymig stocke les données suivantes exclusivement sur ton appareil : Crises migraineuses — date, durée, intensité, localisation céphalée, médicaments pris Contexte automatique — météo, pression barométrique, sommeil, variabilité cardiaque, cycle menstruel (via Apple Santé) Habitudes — caféine, alcool, repas, hydratation, écrans Profil — sexe, tranche d’âge, noms de praticiens (optionnels) 2. Utilisation des données Les données sont utilisées uniquement pour : Analyser les corrélations entre facteurs et crises Générer des rapports cliniques PDF (exportés manuellement) Afficher des conseils personnalisés 3. Partage de données Aucun partage. Ymig ne transmet aucune donnée à des tiers. L’app ne contient aucun SDK d’analytics, aucun tracker, aucune publicité. La seule communication réseau est une requête météo ponctuelle (OpenWeatherMap) au moment d’une crise pour récupérer la pression barométrique et la qualité de l’air. Seules les coordonnées GPS sont envoyées ; aucun identifiant personnel n’est transmis. 4. Apple Santé (HealthKit) Ymig lit (en lecture seule) les données suivantes depuis Apple Santé, avec ton autorisation : Sommeil Variabilité cardiaque (VFC / SDNN) Fréquence cardiaque Cycle menstruel Activité physique Ymig n’écrit jamais dans Apple Santé. Ces données restent sur ton appareil. 5. Localisation Ymig demande ta position uniquement au moment d’une crise, pour récupérer les conditions météo locales. La position n’est pas stockée. 6. Stockage et sécurité Toutes les données sont stockées dans une base locale (SwiftData) protégée par le chiffrement natif d’iOS (Data Protection). Aucune sauvegarde cloud n’est effectuée par l’app. 7. Tes droits (RGPD) Accès — toutes tes données sont visibles dans l’app Portabilité — export PDF depuis Profil → Export Rectification — modification directe dans l’app Effacement — suppression totale depuis Profil → Confidentialité 8. Enfants Ymig n’est pas destiné aux enfants de moins de 17 ans. 9. Contact Pour toute question relative à la confidentialité : alexandre.catteau@hotmail.fr
